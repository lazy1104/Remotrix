# ED2K 设置功能实现计划

## 背景

- aria2-next（引擎 sidecar）自带原生 ED2K 支持。当前应用设置页的 ED2K 分类只是 "Coming Soon"（`src/ui/settings_page.rs:483`）。
- **ED2K 是任务级、按需启动**，与普通下载不冲突：aria2-next 仅在存在 `ed2k://` 下载任务时才创建 `Ed2kListenCommand`/`Ed2kKadCommand`（TCP 默认 4662、UDP 默认 4672），最后一个 ED2K 任务结束后监听自动停止。HTTP/FTP/BT 下载完全不受影响。因此**无需 "启用/禁用 ED2K" 开关**。
- **ED2K 选项仅支持启动时生效**：6 个 `--ed2k-*` 选项均未标记 `setChangeGlobalOption`（已核对 aria2-next `OptionHandlerFactory.cc`），无法通过 JSON-RPC `changeGlobalOption` 热更新，必须作为 CLI 参数在引擎启动时传入。

## 已确认决策

1. 设置页 ED2K 分类提供全部 6 个配置项：ed2k-server、ed2k-server-list、ed2k-node-list、ed2k-listen-port、ed2k-udp-listen-port、ed2k-upload-slots。
2. Apply 行为：若 ED2K 字段有变更，保存配置 + 发送 `EngineCmd::RestartEngine` 自动重启引擎使配置立即生效。
3. server.met / nodes.dat 使用 `PathPicker`（文件模式），新增两个 `PathPickerId` 变体。

## 按文件修改

### 1. `src/config.rs`
- `Aria2Options` 新增字段（serde default + `Default` impl）：
  - `ed2k_server: String`（默认空）
  - `ed2k_server_list: String`（默认空）
  - `ed2k_node_list: String`（默认空）
  - `ed2k_listen_port: u16`（默认 4662）
  - `ed2k_udp_listen_port: u16`（默认 4672）
  - `ed2k_upload_slots: u16`（默认 3）
- 新增 `Aria2Options::ed2k_startup_args(&self) -> Vec<String>`：返回 `--ed2k-*` 参数；空字符串字段（server/server-list/node-list）跳过，端口与槽位始终输出。
- 新增 `Aria2Options::ed2k_equal(&self, other: &Aria2Options) -> bool`：比较 6 个 ED2K 字段，供 Apply 判断是否需要重启引擎。
- **`to_aria2_task_options()` 不得包含 ED2K 字段**（`changeGlobalOption` 会拒绝未知/不可热更选项，导致整批失败）。现有调用方（boot 时应用全局选项、ApplySettings）不受影响。

### 2. `src/message.rs`
- `SettingKey` 新增：`Ed2kServer`、`Ed2kServerList`、`Ed2kNodeList`、`Ed2kListenPort`、`Ed2kUdpListenPort`、`Ed2kUploadSlots`。
- `PathPickerId` 新增：`Ed2kServerList`、`Ed2kNodeList`。
- `PathPickerId::is_folder()` 对两个新变体返回 `false`。

### 3. `src/engine.rs`
- `Sidecar::spawn`（约 257 行）：现有 `.arg(...)` 链之后、`.spawn()` 之前，`let settings = crate::config::load();` 并将 `settings.aria2.ed2k_startup_args()` 逐个 `.arg()`。每次 boot（启动/重启/RetryAria2Fetch）都会重新读取配置，无需其他改动。

### 4. `src/app.rs`
- `Message::SettingChanged`：新增 6 个 match 分支（文本字段直接赋值；端口/槽位 `parse::<u16>()`）。
- `picker_mut`：新增两个变体 → `state.settings_ui.ed2k_server_list_picker` / `ed2k_node_list_picker`。
- `apply_path`：新增两个变体 → 写入 `state.settings.aria2.ed2k_server_list` / `ed2k_node_list`，`picker.set_value(...)`，`close_history()`（文件模式无历史，不调用 `record_path`）。
- `pick_path`：改为按 id 匹配；`Ed2kServerList` 用 `add_filter("ED2K server list", &["met"])`，`Ed2kNodeList` 用 `add_filter("Kad nodes", &["dat"])`（并加 "All files" 过滤，允许任意文件）。
- `revert_apply_settings`：重置 `settings.aria2` 后同步两个 picker 的显示值。
- `Message::ApplySettings` 与 `Message::ApplyAndLeaveSettings`：现有保存 + `ApplyAria2Options` 逻辑之后，若 `!state.settings.aria2.ed2k_equal(&state.applied_settings.aria2)`，再发送 `EngineCmd::RestartEngine`（与 `Message::RestartEngine` 相同的发送方式，见 app.rs:1354）。

### 5. `src/i18n.rs` + FTL 文件
- `Tr` 新增变体及 key：`Ed2kSettings`→`ed2k-settings`、`Ed2kServer`→`ed2k-server`、`Ed2kServerList`→`ed2k-server-list`、`Ed2kNodeList`→`ed2k-node-list`、`Ed2kListenPort`→`ed2k-listen-port`、`Ed2kUdpListenPort`→`ed2k-udp-listen-port`、`Ed2kUploadSlots`→`ed2k-upload-slots`、`Ed2kRestartHint`→`ed2k-restart-hint`。
- `i18n/locales/en/main.ftl` 与 `zh-CN/main.ftl` 添加对应文案（中文示例：`ed2k-settings = ED2K 设置`、`ed2k-server = ED2K 服务器（host:port,...）`、`ed2k-server-list = server.met 文件`、`ed2k-node-list = nodes.dat 文件`、`ed2k-listen-port = TCP 监听端口（0=自动）`、`ed2k-udp-listen-port = UDP 监听端口（0=自动）`、`ed2k-upload-slots = 上传槽位`、`ed2k-restart-hint = ED2K 设置在引擎重启后生效`）。

### 6. `src/ui/settings_page.rs`
- `SettingsUiState` 新增 `ed2k_server_list_picker: PathPicker`、`ed2k_node_list_picker: PathPicker`；`new()` 中用 `PathPicker::file(settings.aria2.ed2k_server_list.clone())` / `PathPicker::file(settings.aria2.ed2k_node_list.clone())` 初始化。
- `view()` 分发改为 `SettingsCategory::Ed2k => ed2k_view(fluent, theme, settings, settings_ui)`。
- 替换 `ed2k_view` 内容：
  - 分组 "ED2K 设置"（`Ed2kSettings`）：`labeled_text_input`（ed2k-server）、两个文件选择器行（复用下载目录行的样式：label 宽 200 + `PathPicker::view`，`Message::PathPicker(PathPickerId::Ed2kServerList, e)` / `(PathPickerId::Ed2kNodeList, e)`）。
  - 分组 "网络与上传"（`Tr::Network`）：`labeled_number`（Ed2kListenPort，`0..=65535u16`）、`labeled_number`（Ed2kUdpListenPort，`0..=65535u16`）、`labeled_number`（Ed2kUploadSlots，`1..=u16::MAX`）。
  - 底部提示文字 `Ed2kRestartHint`（`theme::style::text::secondary`）。
- 删除 "Coming Soon" 占位。`ed2k_view` 需要 `theme` 参数取 accent / text_secondary（与 `bittorrent_view`/`network_view` 一致）。

## 验证

```bash
cargo build
cargo clippy --workspace
cargo fmt --check
```

手动验证：
1. 打开 设置 > ED2K，确认 6 个控件渲染正常，默认值为空/4662/4672/3。
2. 修改端口后点 Apply：引擎自动重启，日志中 sidecar 启动命令包含 `--ed2k-listen-port` 等参数；普通下载任务通过 session 恢复。
3. 确认 boot 时的 `changeGlobalOption` 仍成功（ED2K 键已从 `to_aria2_task_options` 排除）。
4. 添加一个 `ed2k://` 链接，确认使用配置的服务器/端口下载（LowID 提示属正常网络环境现象）。
5. 只改非 ED2K 设置（如限速）Apply 时**不**触发引擎重启。

## 风险与备注

- 自动重启会短暂中断活动下载，但任务经 `--input-file`/`--save-session` 恢复（与更新流程相同机制）。
- 4662/4672 端口仅在存在 ED2K 任务时绑定，不会常开监听。
- aria2-next 的 session 文件会自动持久化 ED2K 隐藏状态（server-state / peer-credit / client-hash / kad-routing-state），无需额外处理。
