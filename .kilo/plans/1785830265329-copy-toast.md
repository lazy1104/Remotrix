# Plan: Shared clipboard-write helper + "Copied" toast

## Goal
All copy surfaces (About dialog text, Settings path fields, task-list link)
write to the clipboard and confirm with a "已复制" / "Copied to clipboard" toast.
Since all three handlers are identical (write clipboard + toast), unify them
behind one shared method instead of duplicating the toast-spawn code.

## Context (verified)
- A toast system already exists. `app.rs` has `spawn_toast(state, group, kind, message, close_after, show_close) -> u64` (app.rs:3203) wrapping `state.toasts.spawn(...)`.
- `ToastKind::Success`, `ToastGroup::General`, default position `Top`.
- `ToastManager::push` auto-removes prior auto-closing toasts in the same group/position, so repeated copy toasts replace each other (no stack growth).
- The three copy handlers live in `app.rs`; each currently returns a clipboard `Task` directly:
  - `Message::CopyText(s)` (app.rs:2685) — used by `copyable_text` in `about_dialog.rs`.
  - `Message::Task(TaskMsg::CopyPath(s))` (app.rs:889) — used by `path_picker` via `settings_page.rs:1682`.
  - `Message::Task(TaskMsg::CopyTaskLink(gid))` (app.rs:2639) — task list "Copy link" button (`task_list.rs:373`). **Confirmed in-scope** (user: "task_list.rs 中复制链接也是的").
- `update()` returns `iced::Task<Message>`; `clipboard::write` returns a `Task` that must be returned, while the toast is a state mutation — so the shared helper mutates state and returns the `Task`.

## Implementation

### 1. Add shared helper `copy_to_clipboard` in `src/app.rs`
Place next to `spawn_toast` (app.rs:3203). It writes to the clipboard and shows
the toast, guarding against empty content:
```rust
fn copy_to_clipboard(state: &mut Remotrix, content: String) -> Task<Message> {
    if content.is_empty() {
        return Task::none();
    }
    spawn_toast(
        state,
        ToastGroup::General,
        ToastKind::Success,
        state.fluent.get(Tr::Copied),
        Some(Duration::from_secs(2)),
        false,
    );
    iced::clipboard::write::<Message>(content)
}
```
(Return type is the `Task` type already used across `update()`; confirm `Task` is
imported in `app.rs` — it is, since handlers return `Task::none()`.)

### 2. Add i18n key `Copied` in `src/i18n.rs`
- Add `Copied,` to the `Tr` enum (near `Copy`, line ~304).
- Add `Tr::Copied => "copied",` to the `key()` match (near `Tr::Copy => "copy"`, line ~590).
- Add to both ftl files after the `copy` line (zh-CN/main.ftl:235, en/main.ftl:235):
  - zh-CN: `copied = 已复制`
  - en: `copied = Copied to clipboard`

### 3. Rewire the three handlers to use the helper
Each handler resolves the content string, then delegates to `copy_to_clipboard`.
Empty-content guards move into the helper, so handlers are minimal.
- `Message::CopyText(s)` (app.rs:2685):
  ```rust
  Message::CopyText(s) => return copy_to_clipboard(state, s),
  ```
- `Message::Task(TaskMsg::CopyPath(s))` (app.rs:889):
  ```rust
  Message::Task(TaskMsg::CopyPath(s)) => return copy_to_clipboard(state, s),
  ```
- `Message::Task(TaskMsg::CopyTaskLink(gid))` (app.rs:2639): keep the no-task guard, resolve URL vs magnet, then delegate:
  ```rust
  Message::Task(TaskMsg::CopyTaskLink(gid)) => {
      let Some(t) = state.tasks.get(&gid) else {
          return Task::none();
      };
      let content = if !t.url.is_empty() {
          t.url.clone()
      } else if let Some(hash) = t.info_hash.as_deref() {
          if hash.is_empty() {
              return Task::none();
          }
          format!("magnet:?xt=urn:btih:{hash}")
      } else {
          return Task::none();
      };
      return copy_to_clipboard(state, content);
  }
  ```
- `Duration` and `Tr` are already imported in `app.rs` (existing `spawn_toast` calls use both). No new imports needed.

### Notes
- `ToastGroup::General` + `ToastKind::Success`, default position `Top`. Short lifetime (2s) keeps it lightweight; dedup handles rapid repeated copies.
- No toast when nothing is copied (empty string / task not found).
