# Icon Fix: About (circle+question) & Task Details (circle+exclamation)

## Goal
1. **About icon** (sidebar): change from `info` (circle+i) to **circle + question mark** (Lucide `circle-question-mark`, codepoint U+E082).
2. **Task view-details icon** (task card): change from `file-text` to **circle + exclamation mark** (Lucide `circle-alert`, codepoint U+E077).
3. Audit all other icons for correctness.

## Audit result (others already correct — no changes)
- Sidebar: `list` (Tasks), `plus` (New), `settings` (Settings) — correct.
- Task toolbar: sort `arrow-up-down`, `refresh`, `play` (Start all), `pause` (Pause all), `trash` (Delete all), `eraser` (Clear list), `plus` (New) — correct.
- Task card: pause/play, `folder_open` (show in folder), `copy` (copy link), `trash` (delete), `connections` (plug) — correct.
- Title bar: `minus` / `copy` (restore-down when maximized) / `square` (maximize) / `x` (close) — correct.
- Category bar: `layers`, `download_arrow`, `circle_check`; settings cats `sliders`/`download`/`magnet`/`share`/`globe`/`wrench` — correct.
- Toasts: `info`/`triangle_alert`/`circle_x`/`circle_check` — correct (keeps `info` in use).
- File tree, path picker, torrent upload, number stepper, dialog close `x` — correct.

## Steps

### 1. `fonts/icons.toml`
- Remove line: `details = "file-text"`
- Add lines (alphabetical placement with other `circle_*` entries):
  ```toml
  circle_alert = "circle-alert"
  circle_help = "circle-question-mark"
  ```
- Keep `info = "info"` (still used by `ToastKind::Normal`).

This regenerates `src/ui/icon.rs` (new `circle_alert()`/`circle_help()` fns, `details` fn removed) and subsets `fonts/lucide.ttf` on next build. Build.rs already reruns on `fonts/icons.toml` change — do not hand-edit generated files.

### 2. `src/ui/sidebar.rs` — About icon
- Add `use crate::ui::icon;` and `Text` to the iced widget import (`use iced::widget::{button, column, container, image, text, Text};`).
- Refactor `icon_btn` closure to accept an `iced::widget::Text` glyph instead of a raw `char` codepoint (drop the `.font(iced::Font::with_name("lucide"))` construction — `icon::*` fns already apply the lucide font).
- Update call sites:
  - Tasks: `icon::list().size(FONT_DIALOG_TITLE).line_height(1.0)`
  - New: `icon::plus().size(FONT_DIALOG_TITLE).line_height(1.0)`
  - About: `icon::circle_help().size(FONT_DIALOG_TITLE).line_height(1.0)` ← the actual fix
  - Settings: `icon::settings().size(FONT_DIALOG_TITLE).line_height(1.0)`

### 3. `src/ui/task_list.rs` — task details icon
- Line 307: `icon::details()` → `icon::circle_alert()`.

### 4. Rebuild & validate
```bash
cargo build              # regenerates src/ui/icon.rs + fonts/lucide.ttf
cargo clippy --workspace # no warnings allowed

```

## Risks / notes
- The generated `src/ui/icon.rs` and `fonts/lucide.ttf` are committed artifacts; the build rewrites both. Verify the git diff includes the regenerated hash line in `icon.rs` and the updated TTF.
- `file-text` glyph is removed from the font — only `icon::details()` used it; it is the one being replaced.
- Codepoints are stable Lucide codepoints: `circle-question-mark` = U+E082 (57474), `circle-alert` = U+E077 (57463), verified against `iced_lucide-0.1.0/assets/unicode.html`.
