# History Dropdown Icon → folder-clock

## Goal
Replace the path-history dropdown button's icon (currently Lucide `list`) with Lucide `folder-clock`, since the button surfaces recently-used folder/file paths.

## Context (verified)
- Icons are generated at build time: `build.rs` calls `iced_lucide::build("fonts/icons.toml")`, which regenerates `src/ui/icon.rs` from `fonts/icons.toml`. The module `src/ui/icon.rs` must NOT be edited by hand.
- `fonts/icons.toml` maps a local snake_case key → Lucide kebab-case glyph name (e.g. `folder_open = "folder-open"`, `refresh = "refresh-cw"`).
- `folder-clock` exists in `iced_lucide 0.1.0` (confirmed in `assets/unicode.html`).
- `icon::list()` is used **only** as the history dropdown button glyph, in two places in `src/ui/path_picker.rs`:
  - line 83: disabled state (history empty)
  - line 89: enabled state (history non-empty, `on_press TogglePathHistory`)
- Unused generated icon `pub fn`s do not trigger clippy `dead_code` warnings (currently `eraser`, `info`, `plus`, `refresh`, `settings`, `sort` are unused and `cargo clippy --workspace` is clean).

## Files to edit

### 1. `fonts/icons.toml`
- Remove the now-fully-unused entry: `list = "list"`.
- Add a new entry: `folder_clock = "folder-clock"`.

Resulting section (keep alphabetical-ish ordering consistent with existing file):
```toml
folder_clock = "folder-clock"
folder_open = "folder-open"
```
(`list = "list"` line is deleted; no other toml changes.)

### 2. `src/ui/path_picker.rs`
Replace `icon::list()` with `icon::folder_clock()` in both the disabled and enabled history buttons:
- line 83: `button(icon_content(icon::folder_clock().size(15).color(text_secondary)))`
- line 89: `button(icon_content(icon::folder_clock().size(15).color(text_secondary)))`

No other code changes are needed. The `icon` import (`use crate::ui::icon;`) is unchanged; `path_picker.rs` already imports `icon`.

## Notes / Risks
- `src/ui/icon.rs` is regenerated by `build.rs` on the next `cargo build` — do not hand-edit it. The build will add `pub fn folder_clock()` and the `("folder_clock", "\u{...}")` pair, and drop the `list()` fn + its `ALL_ICONS` entry.
- `icon::list()` was referenced only by the two replaced call sites, so removing the `list` toml entry causes no compile errors. A `rg "icon::list"` after the change should return nothing.
- The font itself (`fonts/lucide.ttf`) already contains the `folder-clock` glyph codepoint (same font used by the crate), so no font file update is required.

## Out of scope
- Tooltip text / i18n for the history button (currently the button has no tooltip, unlike copy/browse — leave as-is).
- Any change to the disabled vs enabled button styling.

## Validation
- `cargo fmt --check`
- `cargo build` (regenerates `src/ui/icon.rs`; expect success)
- `cargo clippy --workspace` (no warnings)
- `rg "icon::list"` → no matches
- Manual: open Add dialog → save-dir field shows a folder-clock icon on the history (list) button when history is non-empty, and the same glyph (disabled) when empty; toggling opens the path history dropdown as before. Settings → Download page likewise shows the folder-clock history glyph on the download-dir picker.
